# 📘 Descrição

O Gerenciador de Tarefas é uma aplicação web que organiza atividades do dia a dia de forma prática e eficiente.
O foco principal do projeto é o backend, responsável por gerenciar dados, regras de negócio e garantir a comunicação segura e rápida entre o frontend e o banco de dados.

O sistema permite aos usuários criar, editar, visualizar, concluir e excluir tarefas, garantindo que todas as operações sejam registradas de forma confiável.

# 🚀 Funcionalidades

- ✅ Criar novas tarefas
- 📝 Editar tarefas existentes
- ❌ Excluir tarefas
- ✔️ Marcar tarefas como concluídas
- 🔍 Filtrar e listar tarefas por status

# ✅ Requisitos

- Cadastro de usuários

- Interação com os cards

- Criação de quadros

- Criação de alertas

# 🧱 Stack Tecnológica - Foco Backend
🟢 Node.js + Express.js → API REST estruturada e escalável

Node.js permite lidar com múltiplas requisições de forma eficiente, usando programação assíncrona.

Express.js fornece uma estrutura flexível e organizada para criar endpoints REST, middlewares e lógica de negócios.

Justificativa: permite implementar rapidamente todas as operações de CRUD (create, read, update, delete) das tarefas, garantindo alta performance e fácil manutenção.

🗄️ PostgreSQL → banco de dados relacional

Armazena tarefas, usuários e outros dados do sistema de forma estruturada e confiável.

Permite consultas complexas e suporte a relacionamentos entre tabelas, essencial para quadros, alertas e filtros.

Justificativa: escolha madura e escalável.

# 🧱 Stack Tecnológica - Foco Frontend
⚛️ React → criação de SPA moderna e performática

Permite construir uma Single Page Application (SPA) com navegação rápida e sem recarregamento completo.

Componentização facilita reuso e manutenção do código.

Justificativa: ideal para aplicações interativas como o gerenciador de tarefas.

🌐 Renderização: Client-Side Rendering (CSR)

Toda a interface é renderizada no navegador do usuário, garantindo navegação rápida.

Justificativa: mais simples de implementar para SPAs, ideal para aplicações internas como o gerenciador de tarefas.
