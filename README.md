# 📘 Descrição

O Gerenciador de Tarefas é uma aplicação web desenvolvida para facilitar o controle de atividades do dia a dia de forma simples, intuitiva e eficiente.
Com ele, é possível criar, editar, visualizar, marcar como concluídas e excluir tarefas, garantindo uma experiência prática e organizada.

O projeto foi desenvolvido com o objetivo de aplicar conceitos modernos de desenvolvimento full stack, abrangendo frontend, backend, banco de dados e containerização com Docker, seguindo boas práticas e uma arquitetura limpa.

# 🚀 Funcionalidades

✅ Criar novas tarefas

📝 Editar tarefas existentes

❌ Excluir tarefas

✔️ Marcar tarefas como concluídas

🔍 Filtrar e listar tarefas por status

# ✅ Requisitos
- Cadastro de usuários
- Interação com os cards
- Criação de quadros
- Criação de alerta


# 🧱 Stack Tecnológica
- 🖥️ Frontend

⚛️ React → criação de SPA (Single Page Application) moderna e performática

🎨 TailwindCSS → estilização simples, rápida e responsiva

🌐 Renderização: Client-Side Rendering (CSR)

- ⚙️ Backend

🟢 Node.js + Express.js → API REST estruturada e escalável

🗄️ PostgreSQL → banco de dados relacional para armazenamento das tarefas

- 🐋 Infraestrutura

🐳 Docker → containerização da aplicação, garantindo portabilidade e facilidade de deploy

🌍 Nginx → servidor web para o frontend

# 💡 Objetivo

Este projeto tem como foco o aprendizado prático de tecnologias full stack e a implementação de boas práticas de desenvolvimento, como:

Organização modular do código

Separação de responsabilidades

Uso de containers para padronização de ambiente
